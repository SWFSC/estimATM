# estimATM
A tool for planning, execution, analysis, and reporting of CPS biomass from surveys using the acoustic-trawl method (ATM)

## Maintainer
Kevin Stierhoff (@kstierhoff)

# Configuration

The configuration of estimATM on your machine is most easily accomplished using Rstudio and Git. Create a New Project in Rstudio, using the Version Control option, then Git (see **Fig. 1** below). In the repository URL, use "https://github.com/SWFSC/estimATM". You may create this project as a subdirectory of any folder on your computer, for example "C:/CODE". **The project directory name is the critical variable.** The project directory name **must** be the SWFSC designated survey abbreviation, for example "2506SH" for the 2025 Integated West Coast Pelagics Survey conducted aboard the NOAA Ship _Bell M. Shimada_ (see example below; if unsure of the proper abbreviation, contact Kevin Stierhoff or someone else in the SWFSC/FRD Advanced Survey Technologies program). Press "Create Project" to complete the project creation.
